📝 テキストエディタ for Windows

「テキストエディタ for Windows」は、軽量・高速で使いやすい、プログラマーやライター向けのテキストエディタです。
シンタックスハイライトや文字コード切り替え、ライト／ダークテーマ切替など、実用的な機能を備えています。

🖼️ スクリーンショット

🔧 主な機能

  • HTML / C# / XML / JavaScript 対応のシンタックスハイライト
  • UTF-8、Shift_JIS などの文字コードで読み書き可能
  • ライト / ダーク テーマの切り替え
  • 文字数やフォントサイズのステータスバー表示

🔧 使用技術

    C#、WPF、Avalon Editer 文字数やフォントサイズのステータスバー表示
